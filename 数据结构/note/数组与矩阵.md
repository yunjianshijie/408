 * 含有大量相同数据元素

2. 稀疏矩阵
     
3. 上（下）三角矩阵

##  矩阵压缩思想
* 将`相同的数据和0` 尽量压缩成一个存储空间。
* 将二维的数据，变成一维数组。


## 3种矩阵压缩方法

### 对称矩阵
 - 详细看数据矩阵文件

用公式获取方式
```c
int get_index(int i, int j,int * com){
     if(i < j){
        return com[j*(j+1)/2 + i]; //（这里是+1是因为坐标从0开始的）
    }else{
        return com[i*(i+1)/2 + j];
    }
}
``
对称矩阵人如其名，数组下标k和矩阵行列数的关系在复原矩阵是很好解释。
```c
// 从压缩存储恢复原矩阵
int **restore(int *com)
{
    int **result = (int **)malloc(sizeof(int *) * N);
    for (int i = 0; i < N; i++)
    {
        result[i] = (int *)malloc(sizeof(int) * N);
       for (int j = 0 ;j<N ;j++){
            if(i < j){ // 如果行小于列，是上半部分。
                result[i][j] = com[j*(j+1)/2 + i]; // k = j(j+1)/2 +i-1 (公式)  （这里是+1是因为坐标从0开始的）
            }else{ // 是下半部分
                result[i][j] = com[i*(i+1)/2 + j]; // k = i(i+1)/2 +j-1 (公式)
            }
       }
    }
    return result;
}
```

###  下三角矩阵
在上三角区的所有元素为同一常量，所以存储方式和对称矩阵相似，是将下三角区域数据存储在数组中，但是多了一个存储上三角区域的常量的常量项。

* 换算公式参考对称矩阵
* 数组存储是，数组项变成了，（N+1）*N/2 +1 （假设为N价矩阵）
